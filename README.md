# Dotfiles

Personal workstation configuration for macOS.

## Components

- Zsh
- Powerlevel10k
- Ghostty
- Git + Delta
- Bat
- Btop
- Fastfetch
- Lazygit
- VS Code
- Homebrew

## Structure

```
Dotfiles
├── zsh
├── ghostty
├── git
├── bat
├── btop
├── fastfetch
├── lazygit
├── vscode
├── homebrew
├── macos
└── scripts
```
